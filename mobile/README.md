# London Property Services (LPS) — React Native CLI

A mobile-first property maintenance platform for homeowners/landlords and the LPS maintenance team.

## Included flow

### Homeowner
1. Choose a monthly maintenance package.
2. Register/login.
3. Add property details and address.
4. Open maintenance tickets.
5. Describe the repair, choose priority, and add notes/photos later.
6. Receive an LPS quote/invoice.
7. Pay online (demo payment flow is included; connect Stripe for production).
8. See the job marked completed by LPS.
9. Confirm completion.
10. Leave a 1–5 star rating and close the ticket.

### LPS team
1. Login as an admin/demo staff member.
2. View incoming tickets.
3. Set a price and invoice note.
4. Mark a job as completed.
5. View payment status and customer rating.

## Start from a fresh React Native CLI app

The native `android/` and `ios/` folders are intentionally not duplicated in this source pack. They are generated by the React Native CLI and vary by RN version.

```bash
npx @react-native-community/cli@latest init LPSMobile --version 0.81.4
cd LPSMobile
```

Then copy the contents of this pack over the generated project, keeping the generated `android/` and `ios/` folders.

Install packages:

```bash
npm install
cd ios && pod install && cd ..
```

Run:

```bash
npm start
npm run android
# or
npm run ios
```

### Online payments

The included `paymentService.ts` is deliberately an interface/mock. For production, use a provider such as Stripe PaymentSheet with a backend-created PaymentIntent. Never put secret Stripe keys in the mobile application.
