# Production launch checklist

- [ ] Real PostgreSQL with automated backups
- [ ] Production HTTPS API domain
- [ ] JWT secrets generated randomly and stored in a secret manager
- [ ] Stripe live secret, live price IDs and webhook secret
- [ ] Stripe webhook verified and tested with replay
- [ ] Real LPS admin/staff accounts + MFA
- [ ] Apple App ID and signing certificates
- [ ] Android application ID and Play signing
- [ ] App icon/splash assets finalized
- [ ] Privacy policy / terms / cancellation and refund policy
- [ ] UK tax/invoicing review
- [ ] Contractor gas/electrical certification wording reviewed
- [ ] Monitoring, alerting and log redaction
- [ ] Database restore drill
- [ ] TestFlight and Play internal testing
- [ ] Payment failure / cancellation / refund testing
- [ ] Poor-network and offline UX testing
- [ ] Accessibility testing
